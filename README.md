### 🌐 OpenGlucose — Open Standards for Glucose Data

**Founder | Open-Source Initiative**

OpenGlucose is a vendor-neutral, open-source standards ecosystem designed to make glucose data more accessible, portable, and interoperable across devices, applications, and platforms.

The goal is to reduce vendor lock-in and provide a common foundation for healthcare applications, AI systems, researchers, and developers.

**Core initiatives**
- **Open Glucose Telemetry (OGT):** Ingestion, normalization, validation, and routing of glucose data from multiple sources.
- **Open Glucose Interoperability (OGIS):** Standardized glucose data models, JSON schemas, semantic conventions, and provenance.
- **Developer ecosystem:** Open specifications, reference implementations, and tooling for interoperable applications.

**[🌐 OpenGlucose.org](https://openglucose.org)** · **[💻 GitHub Organization](https://github.com/OpenGlucose)** · **[📖 Standards](https://openglucose.org/standards/index.html)**
